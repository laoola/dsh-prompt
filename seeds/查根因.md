帮定位下面问题的根因：

现象：[预期行为 vs 实际行为，尽量精确]
报错/日志：[原文粘贴，不要转述]
相关代码：[粘贴嫌疑路径]
近期变更：[代码/依赖/配置/数据]

要求：
1. 先列候选原因清单，按可能性排序，每个候选说明推理依据。
2. 必须包含非代码候选：依赖版本漂移（lockfile）、配置/环境变量、feature flag、上游 API 变更、数据本身新出现的边界值——这些最常被漏。
3. 给二分策略：先做哪一个检查能最快缩小范围，用什么命令验证。
4. 对每个候选给出证伪证据：出现什么结果就排除它。
5. 修复建议给最小修复（不整体回滚，除非回滚本身是最小修复），并说明如何加回归测试防复发。
