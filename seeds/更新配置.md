本次要做配置类更新：[要改什么，如 AGENTS.md 规则 / 插件清单 / 记忆索引 / profile 配置]。

流程：
1. 先定位真源：这个配置的真源文件在哪、还有哪些地方引用它（README / 总览 / 其他配置 / 记忆索引）。
2. 列影响面清单：要同步改的所有位置（真源 + 引用处），改之前先给我看。
3. 只改真源，引用处同步更新；不手改生成产物（HTML / JSON 报告这类跑脚本产出）。
4. 验证：JSON / YAML 语法、引用路径真实存在、数量一致；涉及插件配置用 dsh --dump-config 核对；涉及记忆索引检查行数 <200 行 / 25KB。
5. 汇报：真源改了哪几行、同步了哪些引用、验证结果、是否需要重跑生成器。
